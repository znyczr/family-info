# 家人档案 · Family Profile

一款**离线可用**的家人信息记录应用（PWA 渐进式 Web 应用）。把家人的基础信息集中记在一处：姓名、身份证号、学校、单位、生日、身高体重、血型血压、尺码、特长爱好、喜欢/忌口的食物、疾病隐患等，随时打开手机就能查，**断网也能用**。

## ✨ 功能

- 📋 记录家人的 **18 项**基础信息（姓名、年龄、身份证号、学校、单位、生日、身高、体重、血型、血压、衣服尺码、裤子尺码、鞋子尺码、特长、爱好、喜欢吃什么、忌口吃什么、疾病隐患、备注）
- 👨‍👩‍👦 预置基础成员：**Daddy、Mommy、Joy、Aaron**，可随时添加/编辑/删除家人
- 🎂 填了生日，年龄自动计算
- 🏷️ 特长、爱好、食物等支持多个标签（逗号或顿号分隔）
- 📦 **导出 / 导入备份**（JSON 文件），换手机或共享数据用
- 📴 **完全离线使用**（Service Worker 缓存）
- 📱 **可安装到手机主屏**，像原生 App 一样独立图标打开
- 🔒 数据只保存在**本机浏览器**里，不上传任何服务器

## 📁 项目结构

```
family-info-app/
├── index.html          # 页面骨架
├── styles.css          # 界面样式
├── app.js              # 数据逻辑（增删改查、导出导入）
├── manifest.json       # PWA 配置（图标、名称、安装）
├── sw.js               # 离线缓存（Service Worker）
├── generate-icons.ps1  # 重新生成应用图标的脚本
└── icons/              # 应用图标（512/192/180）
```

## 🚀 本地预览

在项目目录启动一个 HTTP 服务器（Service Worker 需要 http 协议，不能直接双击打开）：

```powershell
cd C:\Users\Administrator\family-info-app
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080` 即可体验。

## 🌐 部署到网上（手机才能安装）

"安装到手机"需要把应用发布到一个 **HTTPS** 网站。推荐用免费的 **GitHub Pages** 或 **Netlify**，一分钟搞定：

### 方案 A：GitHub Pages（推荐）

1. 在 GitHub 上新建一个公开仓库（例如 `family-info`）
2. 把 `family-info-app` 文件夹里的**全部文件**（含 `icons/`）上传到仓库根目录
3. 进入仓库 **Settings → Pages**，Source 选择 `main` 分支根目录，保存
4. 等 1~2 分钟，页面会给出网址，如 `https://你的用户名.github.io/family-info`
5. 用手机浏览器打开这个网址即可

### 方案 B：Netlify（拖拽部署）

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)，注册登录
2. 把整个 `family-info-app` 文件夹直接**拖进网页**，部署完成
3. 得到网址后即可用手机访问

> 部署到自己的服务器也可以：把文件放到任意 Web 服务器（Nginx/Apache 等）的静态目录，确保启用 HTTPS 即可。

## 📱 安装到手机（离线使用）

### 安卓（Chrome 浏览器）
1. 打开部署好的网址
2. 点浏览器右上角 **⋮ 菜单** → **"添加到主屏幕"**（或 "安装应用"）
3. 主屏出现「家人档案」图标，打开即是独立 App，**断网也能用**

### iPhone / iPad（Safari 浏览器）
1. 打开部署好的网址
2. 点 Safari 底部的 **分享按钮**（方框向上箭头）
3. 选 **"添加到主屏幕"** → 确认
4. 主屏出现「家人档案」图标

> 第一次打开时会弹出现场安装提示条，点「安装」即可。安装后首次务必**联网打开一次**，让应用把资源缓存到手机，之后即可离线使用。

## 💾 数据备份与共享

- 首页右上角 **⬇ 导出**：把全部数据存成 JSON 文件（建议定期备份到网盘/微信收藏）
- 首页右上角 **⬆ 导入**：选择备份文件，一键恢复或迁移到新手机
- 家人的数据保存在**本机浏览器**里。不同手机/浏览器之间互不相通，跨设备请用导出/导入同步。

---

## 🔧 自定义

- **改应用名称 / 颜色**：编辑 `manifest.json`（`name`、`theme_color`）
- **重新生成图标**：运行 `generate-icons.ps1`
- **新增记录字段**：在 `app.js` 的 `FIELD_GROUPS` 里添加即可

## 🔒 隐私说明

所有数据仅存储在您自己设备浏览器的 localStorage 中，应用**无任何后端、无网络上报**，离线可用，请放心记录家人的敏感信息。
